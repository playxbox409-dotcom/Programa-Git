# Control de versiones

El proyecto se trabaja con Git y se relaciona con el repositorio público **Programa-Git**.

Flujo utilizado:

```bash
git status
git add .
git commit -m "Implementado componente front-end de GANA APP"
git push origin master
```

Buenas prácticas aplicadas:

- Commits con mensajes breves y descriptivos.
- Revisión de cambios antes de confirmar.
- Código fuente separado de archivos temporales.
- Enlace del repositorio incluido en la evidencia.
