# Estándares de codificación aplicados

- Archivos, variables y funciones en inglés descriptivo para mantener consistencia técnica.
- Variables y funciones JavaScript en `camelCase`.
- Constantes globales en `UPPER_SNAKE_CASE` cuando corresponda.
- Clases CSS con nombres semánticos y modificadores con doble guion.
- Indentación de cuatro espacios y uso obligatorio de modo estricto en JavaScript.
- Funciones pequeñas con una única responsabilidad.
- Separación entre presentación, lógica de interfaz y persistencia.
- Validación de datos tanto con atributos HTML como con reglas JavaScript.
- Comentarios enfocados en decisiones importantes, evitando describir instrucciones evidentes.
- HTML semántico y atributos de accesibilidad (`aria-label`, `aria-live`, `role`).
- Diseño mobile-first adaptable mediante media queries.
